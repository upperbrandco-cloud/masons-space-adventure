# Mason's Space Adventure 🚀

A browser space-adventure game for Mason. The intended production website uses the **Sharper Edition** supplied in ChatGPT.

## Publish the existing game
1. Download the ready-to-upload `index.html` from the ChatGPT conversation.
2. In this repository, choose **Add file → Upload files** and upload `index.html` at the repository root. Commit to `main`.
3. Open **Settings → Pages** and set the source to **GitHub Actions**. This one-time setup enables Pages; the workflow deploys the site on future pushes to `main`.
4. Once GitHub Pages finishes publishing, visit https://upperbrandco-cloud.github.io/masons-space-adventure/ .

The game is a cinematic browser prototype, not a true Roblox-quality 3D game. No purchases are required.
